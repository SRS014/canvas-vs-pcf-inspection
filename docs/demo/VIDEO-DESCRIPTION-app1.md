**Equipment inspections in Power Apps Canvas: an inspection app built to find exactly where Canvas stops.**

Inspectors check forklifts and conveyors across three warehouse sites. They need a checklist that changes with each answer, a live risk score and photos of any defect, with Dataverse as the record. This proof of concept builds all of that with Canvas controls and Power Fx, then shows the point where the logic stops keeping up with the data.

Built with Power Apps (canvas), Power Fx and Dataverse (6 tables), with no code components. It's tested end to end with Playwright: 23 tests against the published app.
