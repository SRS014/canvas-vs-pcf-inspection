## Main task and arrangement

Main content: the inspections list (R1), taking all remaining space below a single KPI strip. Main action: "New inspection" (A2), fixed at the header's right so it is reachable in every state, including empty and error. KPIs sit above the list because they summarise it; they are one compact row so the list keeps most of the height.

```
+--------------------------------------------------------------+
| S1.R1 header: eyebrow/title ................ [New inspection]|  fixed 72
+--------------------------------------------------------------+
| S1.R2 confirmation banner (only after submit)                |  content-sized
| S1.R3 KPI strip: [Total][Drafts][Submitted][High+Crit][Avg][Built with] | fixed 104
| S1.R4 Inspections card                                       |  remaining space
|   title row + column headers (fixed inside card)             |
|   rows ................................ (scroll owner)       |
+--------------------------------------------------------------+
```

Vertical budget at 1366 x 768: header 72, top margin 24, KPI strip 104, gap 16, list card to bottom margin 24 -> card 528 px: title row 56 + column header 40 + about 6.5 rows of 64 px. With the banner (48 + 16 gap) about 5.5 rows remain. At 1366 x 650: about 4.5 rows (3.5 with banner). Only S1.R4's row area scrolls; the page itself does not.

## Regions

### S1.R1 Header (fixed)
- Purpose: app identity and the screen's only forward action.
- Content: eyebrow "APP 1 · BUILT WITH CANVAS"; title "Equipment inspections". Right: "New inspection" primary button (48 px, with a plus glyph and the label).
- Actions/states: New inspection -> S2 with nothing preselected (A2). Enabled in Loading, Empty and Load-failure states (A2 has no precondition).

### S1.R2 Submit confirmation banner (content-sized, conditional)
- Purpose: confirm A15's outcome on arrival from S5.
- Content: success banner, label "Submitted", message "INS-nnnnn submitted with risk 62.5 · High." (the risk badge inline, compact size), and a "Dismiss" text button (48 px hit area).
- States: shown only on arrival after a successful submit; cleared on Dismiss or when leaving S1. Not auto-timed, so it cannot be missed. Absent on launch, after Cancel from S2, and after Abandon from S3.
- Hierarchy: sits between header and KPIs so it is the first thing read; pushes content down by 64 px (accepted: it is rare and dismissible).

### S1.R3 KPI strip (fixed height 104)
- Purpose: summary figures (Q1 default).
- Content, left to right, six equal white tiles (16 px gaps), each with a 3 px secondary accent along the top, a 14 px muted label and a 32 px figure:
  1. Total inspections
  2. Drafts
  3. Submitted
  4. High + Critical (submitted)
  5. Average submitted score, figure shown as "48.3" with muted "/ 100"; "No submitted inspections" in muted text when none
  6. Built with: two stacked lines "Canvas only  12" and "Canvas + PCF  3" (14 px label, 18 px semibold figure) instead of one big figure
- States: Loading -> each figure shows a muted "..." placeholder, never 0. Load failure -> the strip is replaced by an error banner of the same height (see S1.R4 states) so failed data is never shown as zeros (R12). Empty -> figures show genuine 0 and the average tile shows "No submitted inspections".
- Delegation (A-11): if discovery cannot keep counts correct beyond delegation limits, a one-line muted "Note" below the strip states the limit (for example "Counts cover the first N inspections"). Space is reserved only when the note is shown.
- KPI tiles are informational, not filters; they have no press behaviour.

### S1.R4 Inspections list card (remaining space; row area is the scroll owner)
- Purpose: all inspections, newest first (Q4 default), read-only (A-1).
- Card title row (fixed inside card, 56 px): "Inspections" section heading + muted "Newest first".
- Column headers (fixed inside card, 40 px, 14 px muted semibold): Inspection · Equipment · Site · Status · Risk · Built with.
- Row (min 64 px, 1 px #CBE2EC divider, two text lines where noted):

| Column | Width at 1366 | Content |
|---|---|---|
| Inspection | 200 | Number (16 semibold) over started-on date (14 muted) |
| Equipment | remaining | Equipment name (16) over asset tag (14 muted) |
| Site | 220 | Site name (16) over site code (14 muted) |
| Status | 140 | Status pill (Draft / Submitted) |
| Risk | 180 | Compact risk badge "62.5 · High"; Drafts show "Not scored" (A-1) |
| Built with | 160 | Built with tag (CANVAS ONLY / CANVAS + PCF) |

- Rows are not interactive: no chevron, no pressed state, no focus stop per row (A-1). Rows remain readable by assistive tech in column order.
- States, centred in the row area:
  - Loading: spinner + "Loading inspections...".
  - Empty: "No inspections yet" + muted "Start one with New inspection." (the header button stays the action; no duplicate button).
  - Load failure: error banner at the top of the card body: label "Error", "Inspections couldn't be loaded. Check your connection and try again." with a "Try again" secondary button that re-runs A1. The list area stays empty; KPI strip replaced as above.
  - Arrival after abandon (A16, Q2): list refreshed; the abandoned inspection appears as Draft / Not scored. No banner.
  - Arrival after submit: list refreshed; the submitted row shows Submitted + its band badge.

## Reading and focus order

Header title (announced as the screen heading) -> New inspection -> confirmation banner and its Dismiss (announced politely on arrival) -> KPI tiles left to right -> list title -> column headers -> rows top to bottom (read-only content). Initial focus on arrival: the banner when present, otherwise the screen heading.

## Accessibility intent

- Risk is never colour-only: badge text always carries score and band word; status uses words, not colour.
- KPI tiles expose label + value together ("Drafts, 4").
- Error and empty messages are text in the list region, not toasts.

## Viewport changes

- 1024 x 768: KPI tiles shrink to about 149 px each; labels may wrap to two lines (tile height stays 104). The Site column is removed and the site name moves into the Equipment column's second line ("asset tag · site name"). Column widths: Inspection 170, Equipment remaining, Status 120, Risk 150, Built with 130.
- 1366 x 650: unchanged layout; the list row area shrinks (about 4.5 rows). KPI strip does not compact.
- 1920 x 1080: body capped at 1600 px, centred; Equipment column absorbs extra width; about 12 rows visible.
